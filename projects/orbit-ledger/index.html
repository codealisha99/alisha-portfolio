OrbitLedger

A crypto paper-trading workspace for BTC, ETH and SOL: real market data, virtual money.

Open the live site ↗ View the code ↗

● liveTypeScriptgithub.com/codealisha99/orbit-ledger

What it is

OrbitLedger lets you practise trading with virtual USD collateral. Execution quotes are simulated from Binance public trades, so prices move like the real market, but no real assets are ever bought or sold.

Leveraged positions are simulated linear perpetuals with no expiry and a fixed, educational funding rule of 1 basis point every 8 hours. The dashboard reconciles available cash, reserved collateral and signed P&L so every number can be traced.

How it works

  1. Price poller: streams Binance aggregate trades and publishes simulated quotes.
  2. Backend: Express on Bun with Prisma/PostgreSQL, a five-second risk cycle and a durable event outbox.
  3. WebSocket service: public market feeds plus private, versioned account events that reconcile after reconnects.
  4. Frontend: Next.js 15 and React 19 with lightweight-charts and a single managed real-time transport.

Run it yourself

cp .env.example .env
bun install
docker compose up -d   # PostgreSQL + Redis
bun run prisma generate
bun run prisma migrate deploy
bun run dev
