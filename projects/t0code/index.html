t0code

A local workspace for coding agents: in the browser, the terminal or the desktop.

Open the live site ↗ View the code ↗

● liveTypeScriptgithub.com/codealisha99/t0code

What it is

t0code runs coding agents on your own machine and gives them one workspace. A local server holds the sessions, projects and git state, and you drive it from whichever surface you like.

The same server backs a React web app, a terminal UI and an Electron desktop shell, so a session started in one can be picked up in another.

How it works

  1. Server: a local WebSocket server runs agent sessions, git, terminals and checkpoints, backed by SQLite.
  2. Web: a React app for chat, the composer, diffs and settings.
  3. Terminal: a full terminal UI for working without leaving the shell.
  4. Desktop: an Electron shell that bundles the server and the web UI.

Built with
