SchemaGuard

Turn messy LLM output into validated JSON, and see every repair it made.

Open the live site ↗ View the code ↗

● livePythongithub.com/codealisha99/schemaguard

What it is

Language models often return almost-JSON: trailing commas, single quotes, missing brackets. SchemaGuard repairs common syntax errors, validates the result against strict schemas, and shows exactly what it changed.

The playground needs no model calls, API keys, signup or database.

How it works

  1. Paste: drop in raw model output.
  2. Repair: common JSON syntax errors are fixed, and each fix is recorded.
  3. Validate: the repaired JSON is checked against one of three strict schemas.
  4. Inspect: review the repair notes, or use the same pipeline through the API.

Built with

  • Python
  • FastAPI
  • Vanilla HTML/CSS/JS
  • JSON Schema
  • pytest

Run it yourself

python3 -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m app.run   # http://localhost:8006/playground
