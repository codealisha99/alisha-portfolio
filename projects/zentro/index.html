Zentro

Peer-to-peer video calls in the browser. Share a link; no accounts, no downloads.

Open the live site ↗ View the code ↗

● liveTypeScriptgithub.com/codealisha99/zentro

What it is

Zentro connects two people directly. Video and audio travel between the participants over WebRTC, so the media never touches a server.

The only server is a small signaling service that introduces the two browsers and then steps out of the way. It keeps no history.

How it works

  1. Lobby: you create a room and share its link.
  2. Signaling: a Node WebSocket server pairs two clients per room and relays the SDP offer/answer and ICE candidates.
  3. Call: once connected, all media flows peer-to-peer, with a video grid, controls, chat and a participant list.
  4. Transcript (optional): local audio recording can be transcribed with Groq's Whisper model.

Built with

  • TypeScript
  • Next.js
  • WebRTC
  • WebSockets
  • Node
  • pnpm + Turborepo

Run it yourself

pnpm install
pnpm --filter @webrtc-conf/signaling dev   # signaling on :8080
pnpm --filter @webrtc-conf/web dev
