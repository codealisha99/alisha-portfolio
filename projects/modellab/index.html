ModelLab

A small developer lab for simulated training, ranked memory and resumable token streams.

Open the live site ↗ View the code ↗

● livePythongithub.com/codealisha99/modellab

What it is

ModelLab is a workbench for the plumbing around models: follow a dataset from training to evaluation, explore how a three-tier memory ranks what it recalls, and break a streaming connection to watch every token come back.

Training is simulated, so it needs no external API keys, database or GPU locally. On 2026-10-12 the README records 153 passing tests at 90.19% coverage.

How it works

  1. Train: a simulated run takes a dataset from training through evaluation.
  2. Remember: ranked three-tier memory shows what gets recalled and why.
  3. Stream: token streams can be interrupted and resumed, and replay proves no token is lost.
  4. Inspect: everything is also exposed through interactive API docs.
