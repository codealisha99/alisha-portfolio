Gambit

Multiplayer chess with clocks the server keeps honest, plus offline play against Stockfish.

Open the live site ↗ View the code ↗

● liveTypeScriptgithub.com/codealisha99/chessandwhatever

What it is

Gambit is chess for two people with a link. Start a game, send the private invite, and play on clocks that the server owns, so nobody's browser can fudge the time.

Games can be watched by spectators, rematched and chatted in. When you're alone, play offline against Stockfish 19 or open the analysis board.

How it works

  1. Invite: a private link drops your opponent straight into the game.
  2. Play: every move is validated on the server with chess.js, and the server-authoritative clocks are pushed over WebSockets.
  3. Watch: spectators follow live; rematches and chat keep the same room.
  4. Practice: Stockfish 19 runs in the browser for offline games and analysis.
