Sherlock

See where a codebase is weak before you read a line of it.

Open the live site ↗ View the code ↗

● livePythongithub.com/codealisha99/sherlock

What it is

Paste a GitHub repository. Sherlock maps the code into an interactive graph, marks security, quality and dependency findings on that map, and scores the repository out of 100.

For a deeper read, a pipeline of six specialised agents running on a local Ollama model writes a technical briefing that explains the codebase from first principles. That stage keeps source code on your machine.

How it works

  1. Ingest: clones the repository, indexes it with tree-sitter and scans it. This stage needs no language model.
  2. Graph: files, classes and functions become an interactive map, coloured by what was found in them.
  3. Findings: security, dependency (via osv.dev), maintainability, quality, secrets and testing issues, with severity and triage filters.
  4. Agent briefing: Repository Mapper, Flow Tracer, Component Analyst, Data & Integration Analyst, Gap Analyst and Teacher build the full report on a local model.

Built with

  • Python
  • tree-sitter
  • pydantic
  • httpx
  • osv.dev
  • Ollama
  • Vanilla JS

Run it yourself

python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.main --serve          # web UI on :8080
# optional, for the agent briefing:
ollama pull qwen3-coder:30b-16k && ollama serve
