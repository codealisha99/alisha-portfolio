thedaaakhouse

A job-search operating system: track applications, tailor résumés, prepare for interviews.

Open the live site ↗ View the code ↗

● liveNext.jsgithub.com/codealisha99/thedaaakhouse

What it is

One application connects its job description, the résumé version you sent, ATS checks, interview plans and company research, all in one workspace.

It's evidence-driven. Tailored résumés are extractive, so bullets are reordered and never rewritten. ATS scores show their method. Anything missing from your profile is reported, never invented.

How it works

  1. Track: a spreadsheet-style job tracker with status history.
  2. Analyze: paste a job description or URL to pull out skills, keywords and requirements.
  3. Tailor: résumé versions are reordered against the job, and an ATS checker scores them (50% keywords, 25% skills, 15% experience, 10% formatting).
  4. Prepare: interview questions come from the job description, with an arena for mock sessions and a learning hub.

Run it yourself

# backend (:8001)
python3.12 -m venv backend/.venv && source backend/.venv/bin/activate
pip install -r backend/requirements.txt
uvicorn app.main:app --reload --port 8001
# frontend (:3000)
npm install --prefix frontend
npm run dev --prefix frontend
