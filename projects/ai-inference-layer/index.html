Inference

One model registry and inference API, implemented four times behind a single HTTP contract.

Open the live site ↗ View the code ↗

● livePythongithub.com/codealisha99/ai-inference-layer

What it is

Register a model, run inputs against it, read the history back. The same API is implemented in Python, TypeScript, Go and Rust, and all four share one contract and one response envelope.

The web workbench, Inference, includes a playground. Its classification, generation and embedding engines are deterministic reference implementations for integration testing; they don't call a hosted language model. Alisha maintains the project.

How it works

  1. Register: POST /models with a type: text-generation, text-classification or embedding.
  2. Infer: POST /models/{id}/infer runs an input against the model.
  3. Inspect: GET /models/{id}/inferences reads the history back, paginated.
  4. Reference port: Python/FastAPI adds batching, SSE streaming, Prometheus metrics and API-key auth.

Run it yourself

cd ai-inference-server-py
uv sync --extra dev --locked
uv run ais serve --db ./data/ai.db
# in another terminal: uv run ais demo
