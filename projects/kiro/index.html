Kiro

A company knowledge desk that only answers with what you're allowed to see.

Open the live site ↗ View the code ↗

● liveNext.jsgithub.com/codealisha99/kiro

What it is

Kiro searches a company's documents and answers questions about them, and every answer respects the asker's permissions. If you can't open the source, Kiro won't quote it.

It's built as separate services: a Next.js desk, a Spring Boot core, and a Python service for retrieval, with pgvector for search. The full company-intelligence specification is still being written.

How it works

  1. Ingest: documents are indexed with their access rules attached.
  2. Ask: questions go through the Spring Boot core, which checks who is asking.
  3. Retrieve: a FastAPI service searches PostgreSQL/pgvector, filtered to what the user may read.
  4. Answer: the desk shows the answer with the sources it came from.

Built with

  • Next.js
  • Spring Boot
  • Java 21
  • FastAPI
  • PostgreSQL
  • pgvector
  • Redis
  • Docker

Run it yourself

pnpm install --frozen-lockfile
cp .env.example .env
docker compose up -d --build
